Panduan Penggunaan SATPAM BOK

  1. Admin menyiapkan database Google Sheets dan folder Google Drive melalui petunjuk instalasi.
  2. Operator memilih menu Input SPJ, mengisi data transaksi, mencentang dokumen yang tersedia, lalu mengunggah berkas.
  3. Verifikator membuka menu Verifikasi Dokumen, memeriksa berkas dan menetapkan status.
  4. Pimpinan memantau pagu, realisasi, dan status kelengkapan melalui dashboard serta laporan.
Catatan keamanan: Jangan menyimpan kredensial atau token rahasia di repository GitHub. Batasi akses Google Drive dan spreadsheet hanya kepada petugas berwenang. Data contoh dan konfigurasi awal harus disesuaikan dengan ketentuan pengelolaan BOK yang berlaku.
